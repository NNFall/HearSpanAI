# Процесс публичного релиза

## Обязательные проверки

Перед публикацией установщика:

1. версия приложения, EXE, установщика и changelog совпадает;
2. автоматические тесты проходят;
3. чистая установка проверена на Windows без Python;
4. установщик проверен на секреты и внутренние конфигурации;
5. relay использует шифрование, авторизацию и rate limiting;
6. создан `SHA256SUMS.txt`;
7. release notes содержат возможности, исправления и известные ограничения;
8. README и troubleshooting соответствуют выпущенной версии.

## Статусы

- `draft`: релиз готовится и не виден пользователям;
- `prerelease`: тестовая сборка с известными ограничениями;
- `latest`: рекомендуемая стабильная версия.

Историческая `0.1.2` публикуется только как запись о private beta, без установщика.
