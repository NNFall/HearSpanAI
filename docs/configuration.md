# Конфигурация и ключи

## Режимы доступа

### Relay проекта

Приложение подключается к beta relay HearSpan AI. Пользователь не вводит ключ Google. Текущий relay ещё не переведён на TLS и обязательную авторизацию, поэтому не используйте его для конфиденциальных разговоров.

### Собственный Gemini API-ключ

Пользователь указывает собственный ключ Gemini. Запросы и расходы относятся к его Google-аккаунту. Ключ можно оставить только до закрытия приложения или сохранить через Windows DPAPI для текущего пользователя. Удаление доступно в **Настройки → AI и модели**.

## Переменные окружения

Безопасный пример находится в корневом файле [.env.example](../.env.example):

| Переменная | Назначение |
| --- | --- |
| `GEMINI_API_KEY` | Собственный ключ Gemini для прямого режима |
| `ASSEMBLYAI_API_KEY` | Необязательный ключ экспериментальной транскрибации |
| `TRANSCRIPTION_PROVIDER` | Провайдер транскрибации |
| `GEMINI_LIVE_MODEL` | Модель Live API |
| `GEMINI_ANSWER_MODEL` | Текстовая модель полного ответа |
| `GEMINI_RELAY_WS` | Защищенный WebSocket relay |
| `GEMINI_RELAY_TOKEN` | Токен доступа к relay |
| `HEARSPAN_AUTH_URL` | HTTPS-адрес будущего веб-входа; пока оставьте пустым |

Реальный `.env` нельзя отправлять в GitHub, прикладывать к Issue или включать в диагностический архив.

## Что не должно попадать в публичный репозиторий

- значения API-ключей и токенов;
- пароли и SSH-ключи;
- внутренние IP-адреса и команды развертывания;
- полные пользовательские логи и транскрипции;
- исходный код приложения и relay.
