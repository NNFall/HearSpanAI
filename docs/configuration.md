# Конфигурация и ключи

## HearSpan Relay

Режим по умолчанию использует защищённый WSS relay. Новая установка автоматически получает 10 минут trial. После trial персональный ключ выдаётся через [@HearSpan_bot](https://t.me/HearSpan_bot?start=docs) и вводится в **Настройки → Обзор**.

Ключ можно проверить, заменить или удалить. При сохранении он защищается Windows DPAPI для текущего пользователя.

## Собственный Gemini API key

В режиме BYOK запросы и расходы относятся к Google-аккаунту пользователя. Ключ можно оставить только до закрытия приложения или сохранить через Windows DPAPI. Удаление доступно в **Настройки → AI и модели**.

## Аудио

- **Микрофон** — выбранное устройство ввода Windows;
- **Системный звук** — устройство вывода с пометкой `Windows loopback`;
- усиление и mute настраиваются независимо;
- если индикатор loopback почти не двигается, убедитесь, что звук реально воспроизводится через выбранное устройство, затем постепенно увеличьте усиление.

## Промпты

- **Системный промпт** задаёт роль и общие правила ответа;
- **Промпт ответа** описывает текущую задачу пользователя;
- при запросе приложение отправляет объединённую историю транскрипции и предыдущих полных ответов, а не отдельные аудиочанки как самостоятельные сообщения.

## Answer Overlay

- отдельное окно ответа включается в **Настройки → Overlay**;
- прозрачность регулируется от 45% до 100%;
- режим поверх других окон и пропуск нажатий мыши настраиваются независимо;
- защита демонстрации исключает только overlay из поддерживаемого Windows-захвата;
- главное окно и настройки остаются видимыми;
- зелёный значок с глазом означает, что Windows приняла защиту.

Перед важной демонстрацией проверьте используемую программу связи или записи:
некоторые способы захвата не поддерживают `WDA_EXCLUDEFROMCAPTURE`.

## Переменные окружения

Обычному пользователю они не нужны. Для диагностического запуска поддерживаются безопасные локальные настройки из [.env.example](../.env.example), включая собственный `GEMINI_API_KEY`, модели и публичные URL HearSpan. Реальный `.env` нельзя отправлять в GitHub, Issue или диагностический архив.

## Что нельзя публиковать

- HearSpan и Gemini API keys;
- пароли, SSH-ключи и Telegram/YooKassa tokens;
- полные пользовательские логи и транскрипции;
- внутренние адреса и deployment-команды;
- исходный код приложения и серверной части.
