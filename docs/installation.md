# Установка

## Текущий статус

Текущий установщик `HearSpan-Setup-0.3.0.exe` опубликован как Windows private beta. Историческая сборка `0.1.2` использовала название AppGhost и распространялась только среди beta-тестировщиков.

Скачивайте установщик только со страницы [HearSpan AI v0.3.0](https://github.com/NNFall/HearSpanAI/releases/tag/v0.3.0). Python устанавливать не нужно.

1. запустите `HearSpan-Setup-0.3.0.exe`;
2. пройдите стандартный мастер Windows и при необходимости включите ярлык на рабочем столе;
3. откройте **Настройки → Аудио и транскрибация**, выберите микрофон и устройство системного звука;
4. перед разговором проверьте движение обоих индикаторов громкости.

## Как будет выглядеть установка

Пользователь скачивает один файл, запускает стандартный мастер Windows и получает ярлыки в меню «Пуск» и на рабочем столе. Python и ручная установка библиотек не требуются. Установщик пока не подписан цифровой подписью, поэтому SmartScreen может показать предупреждение.

После первого запуска пользователь вручную настраивает:

- выбрать микрофон;
- выбрать устройство системного звука;
- проверить оба индикатора громкости;
- выбрать relay проекта или прямой режим Gemini;
- проверить соединение запуском тестовой сессии.

## Проверка файла

Каждый официальный релиз будет содержать файл `SHA256SUMS.txt`. Контрольную сумму в PowerShell можно проверить так:

```powershell
Get-FileHash .\HearSpan-Setup-0.3.0.exe -Algorithm SHA256
```

Сравните полученное значение с опубликованным в том же релизе.

Ожидаемый SHA-256 для `v0.3.0`:

```text
FB2B21B57E60A0DB1F30AA357039F30D3F38AE091B1C04C71A81CBADB4EC9381
```
