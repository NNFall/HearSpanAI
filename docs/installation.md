# Установка

## Скачать

Текущий установщик: `HearSpan-Setup-0.4.0.exe` для Windows 10/11 x64. Скачивайте его только со страницы [HearSpan AI v0.4.0](https://github.com/NNFall/HearSpanAI/releases/tag/v0.4.0). Python устанавливать не нужно.

1. Запустите `HearSpan-Setup-0.4.0.exe`.
2. Пройдите стандартный мастер Windows и при необходимости включите ярлык на рабочем столе.
3. Откройте приложение и дождитесь автоматической активации 10-минутного trial.
4. В **Настройки → Аудио и транскрибация** выберите микрофон и устройство системного звука.
5. Запустите сессию и проверьте движение обоих индикаторов громкости.

Установщик пока не подписан цифровой подписью, поэтому SmartScreen может показать предупреждение. Проверяйте SHA-256 перед запуском.

## Обновление

`0.4.0` устанавливается поверх предыдущей HearSpan/AppGhost beta с тем же Inno Setup AppId. Проверенное тихое обновление сохранило существующий `settings.json`. Перед обновлением всё равно рекомендуется закрыть приложение и сохранить важный пользовательский промпт отдельно.

## Доступ после trial

Откройте [@HearSpan_bot](https://t.me/HearSpan_bot?start=app), получите персональный ключ и вставьте его в **Настройки → Обзор**. Платёжный сценарий текущей beta тестовый: реальных списаний нет.

BYOK остаётся альтернативой: собственный Gemini API key настраивается в разделе **AI и модели**.

## Проверка файла

```powershell
Get-FileHash .\HearSpan-Setup-0.4.0.exe -Algorithm SHA256
```

Ожидаемый SHA-256:

```text
345045ECE09C30D414590999C22523A9E4F5BBF023AAAD817A45C87887D09832
```

Та же строка опубликована рядом с установщиком в `SHA256SUMS.txt`.
