# Установка

## Скачать

Текущий установщик: `HearSpan-Setup-0.6.0.exe` для Windows 10/11 x64. Скачивайте его только со страницы [HearSpan AI v0.6.0](https://github.com/NNFall/HearSpanAI/releases/tag/v0.6.0). Python устанавливать не нужно.

1. Запустите `HearSpan-Setup-0.6.0.exe`.
2. Пройдите стандартный мастер Windows и при необходимости включите ярлык на рабочем столе.
3. Откройте приложение и дождитесь автоматической активации 10-минутного trial.
4. В **Настройки → Готовность** проверьте доступ, затем выберите устройства в разделе **Звук**.
5. Запустите сессию и проверьте движение обоих индикаторов громкости.

Установщик пока не подписан цифровой подписью, поэтому SmartScreen может показать предупреждение. Проверяйте SHA-256 перед запуском.

## Обновление

`0.6.0` устанавливается поверх предыдущей HearSpan/AppGhost beta с тем же Inno Setup AppId. Проверенное тихое обновление сохранило существующий `settings.json`. Перед обновлением всё равно рекомендуется закрыть приложение и сохранить важный пользовательский промпт отдельно.

## Доступ после trial

Откройте [@HearSpan_bot](https://t.me/HearSpan_bot?start=app), получите персональный ключ и вставьте его в **Настройки → Доступ и ключи**. Платёжный сценарий текущей beta тестовый: реальных списаний нет.

BYOK остаётся альтернативой: собственный Gemini API key настраивается в разделе **Доступ и ключи**, а модели и промпты — в **AI и ответы**.

## Проверка файла

```powershell
Get-FileHash .\HearSpan-Setup-0.6.0.exe -Algorithm SHA256
```

Ожидаемый SHA-256:

```text
80E37AB29E014908DD509932C495823A19FBBBAF04D55BC3C971A4742D7585BC
```

Та же строка опубликована рядом с установщиком в `SHA256SUMS.txt`.
