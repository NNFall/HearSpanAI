# Установка

## Текущий статус

Публичный установщик HearSpan AI еще не выпущен. Историческая сборка `0.1.2` использовала название AppGhost и распространялась только среди beta-тестировщиков.

Первый публичный установщик появится на странице [Releases](https://github.com/NNFall/HearSpanAI/releases) после выполнения трех условий:

1. приложение и установщик полностью переименованы в HearSpan AI;
2. relay использует `wss://`, обязательную авторизацию и ограничение нагрузки;
3. сборка проверена на отсутствие ключей и подписана контрольной суммой SHA-256.

## Как будет выглядеть установка

Пользователь скачивает один файл `HearSpan-Setup-x64.exe`, запускает стандартный мастер Windows и получает ярлыки в меню «Пуск» и на рабочем столе. Python и ручная установка библиотек не потребуются.

После первого запуска мастер поможет:

- выбрать микрофон;
- выбрать устройство системного звука;
- проверить оба индикатора громкости;
- выбрать relay проекта или собственный Gemini API-ключ;
- проверить соединение до начала сессии.

## Проверка файла

Каждый официальный релиз будет содержать файл `SHA256SUMS.txt`. Контрольную сумму в PowerShell можно проверить так:

```powershell
Get-FileHash .\HearSpan-Setup-x64.exe -Algorithm SHA256
```

Сравните полученное значение с опубликованным в том же релизе.
