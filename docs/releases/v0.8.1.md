# HearSpan AI 0.8.1

Дата выпуска: 2026-09-23.

## Что изменилось

- Статус приложения прямо сообщает об истёкшем ключе и показывает путь к его замене.
- При ошибке текстового запроса приложение сразу получает её от relay и делает повторную попытку либо показывает итоговую ошибку без лишнего ожидания.
- Если Google отвечает `503`, relay сразу пробует запасную модель. Время ответа по-прежнему зависит от доступности Gemini.
- Для новых установок основной домен — `hearspan-ai.ru`. Ранее установленные версии продолжают работать через прежние адреса.

Настройки, ключ и локальная история остаются на компьютере после установки обновления поверх предыдущей версии.

Примечание: установщик проверяется приложением по подписанным метаданным и SHA-256. Windows Authenticode пока не используется.
