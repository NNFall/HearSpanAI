# HearSpan AI v0.6.0

`v0.6.0` делает Windows-клиент и Telegram-бот понятнее в ежедневной работе:
состояние записи остаётся видимым во время запроса, источники звука показывают
смысловой статус, а настройки сгруппированы по задачам пользователя.

![Активная сессия HearSpan AI](https://raw.githubusercontent.com/NNFall/HearSpanAI/v0.6.0/assets/screenshots/hearspan-session-0.6.0.png)

## Скачать

- установщик: `HearSpan-Setup-0.6.0.exe`;
- Windows 10 версии 2004 или новее, Windows 11, x64;
- Python не требуется.

## Главное

- экран готовности к сессии с прямыми переходами к проблемной настройке;
- статусы аудио `Сигнал`, `Тишина`, `Выкл.` и `Перегруз`;
- отдельный прогресс подготовки и потоковой передачи ответа;
- вкладки ответа и live-совета на компактной ширине;
- семь разделов настроек: готовность, доступ, звук, AI, горячие клавиши, окно ответа и диагностика;
- безопасный диагностический отчёт без ключей и токенов;
- четыре основных действия Telegram-бота и явная маркировка тестовой оплаты.

![Готовность к сессии](https://raw.githubusercontent.com/NNFall/HearSpanAI/v0.6.0/assets/screenshots/hearspan-settings-readiness-0.6.0.png)

## Проверка

- desktop/relay: `267 passed, 1 skipped`;
- control plane/Telegram: `790 passed, 3 skipped`;
- реальные Windows-снимки проверены от `960x640` до `1920x1080` и при scaling `125%`;
- portable EXE и установленное приложение открыли окно `HearSpan AI` и создали журнал;
- тихое обновление сохранило существующий `settings.json` без изменений;
- EXE и установщик сообщают версию `0.6.0`.

## Ограничения beta

- YooKassa остаётся в тестовом режиме, реальные списания отключены;
- установщик не подписан, поэтому Windows SmartScreen может показать предупреждение;
- защита демонстрации применяется только к Answer Overlay и зависит от способа Windows-захвата;
- глобальные горячие клавиши и автоматическое обновление ещё не реализованы.
