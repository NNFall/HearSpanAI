## Новое

### Управление снимком контекста

- После нажатия **Запросить ответ** приложение по умолчанию ждёт `0.4` секунды
  перед сбором текущего контекста.
- Ожидание можно настроить от `0` до `3` секунд или выключить. Финальная
  транскрипция может ещё не прийти; в этом случае в снимок входит доступная
  промежуточная транскрипция. Ожидание не определяется по тишине или громкости
  звука.

### Автоматические ответы

- Режим выключен по умолчанию.
- Отдельная пауза после финальной транскрипции перед автоматическим ответом по
  умолчанию составляет `700` мс и настраивается в диапазоне `300–3000` мс.
- Одновременно выполняется только один автоматический запрос.
- Поздняя финализация и ручной запрос не создают второй ответ на ту же
  реплику.

### Постепенный вывод ответа

Существующий постепенный вывод текстового ответа частями сохраняется. Настройки
ожидания и автоматического режима управляют моментом отправки запроса, но не
заменяют текущий механизм выдачи текста.

## Данные и обновления

- Локальная история, настройки, промпты и сохранённые параметры доступа
  сохраняются при обновлении поверх установленной версии.
- Обновление остаётся подтверждаемым пользователем; активная сессия не
  прерывается внезапной установкой.
