# HearSpan AI v0.5.0

`v0.5.0` добавляет режим приватности для отдельного полупрозрачного окна
ответа. Overlay остаётся видимым пользователю, но исключается из
поддерживаемого Windows-захвата.

![Answer Overlay HearSpan AI](../../assets/screenshots/hearspan-answer-overlay-0.5.0.png)

## Скачать

- установщик: `HearSpan-Setup-0.5.0.exe`;
- Windows 10 версии 2004 или новее, Windows 11, x64;
- Python не требуется;
- размер: `80 092 045` байт;
- SHA-256: `23981134C9F6DE66A33569626139A78E6731209223DB2FA8F589CD98A13297A3`.

Контрольная сумма также приложена как `SHA256SUMS.txt`.

## Что добавлено

- прозрачность Answer Overlay от 45% до 100%;
- опциональное исключение overlay из поддерживаемого Windows-захвата;
- локальный статус защиты: активна, выключена, недоступна или ошибка;
- сохранение настройки между запусками;
- повторное применение защиты после изменения нативных параметров окна.

![Настройки приватности overlay](../../assets/screenshots/hearspan-settings-overlay-0.5.0.png)

## Проверка

- desktop/relay: `253 passed, 1 skipped`;
- реальный screenshot probe: `90 000` контрольных пикселей без защиты и `0`
  после неё;
- упакованный EXE: affinity `0x11` у Answer Overlay и `0x0` у главного окна;
- portable-сборка открыла настоящее окно и создала изолированный профиль;
- тихое обновление `0.4.0 -> 0.5.0` завершилось с кодом `0`, не изменив
  настройки во время установки;
- установленный EXE и установщик сообщают версию `0.5.0`;
- ярлык рабочего стола ведёт на существующий установленный EXE.

## Ограничения beta

- результат зависит от способа захвата, поэтому перед важной демонстрацией
  требуется короткая проверка в используемой программе;
- защищается только Answer Overlay: главное окно и настройки остаются видимыми;
- функция не скрывает процесс и не предназначена для обхода контроля или
  прокторинга;
- установщик пока не подписан цифровой подписью;
- YooKassa остаётся в test mode до закрытия ручных платёжных проверок.
