# AppGhost v0.1.2: историческая private beta

Дата исходного выпуска: `23.07.2026`.

Это последняя тестовая версия продукта до выбора бренда HearSpan AI. Установщик проверен на отдельном Windows-ноутбуке без Python, но не публикуется в открытом доступе из-за старого бренда и незавершенной защиты relay.

## Возможности

- микрофон и Windows loopback в одной сессии;
- независимые индикаторы, усиление и mute;
- Live-транскрибация;
- короткий совет и полный потоковый Markdown-ответ;
- ожидание поздней транскрипции перед запросом;
- сохраняемые настройки, промпты и горячие клавиши;
- локальные статусы и диагностические логи.

## Проверено

- автоматические тесты на Windows;
- чистая установка без Python;
- обнаружение аудиоустройств;
- сохранение настроек при обновлении.

## Ограничения

- старое имя AppGhost и прежняя иконка;
- неподписанный установщик;
- beta relay не готов к публичной нагрузке;
- сборка не предназначена для конфиденциальных разговоров.

Следующий публичный выпуск планируется под именем HearSpan AI.
