# Диагностика

Инструкция относится к текущему Windows-прототипу; названия пунктов могут измениться после обновления интерфейса.

## Устройства не появились

1. Проверьте подключение устройства в Windows.
2. Разрешите приложениям доступ к микрофону.
3. Нажмите **Обновить** рядом со списками устройств.
4. Перезапустите приложение после подключения Bluetooth-гарнитуры.

## Системный звук не транскрибируется

1. Выберите устройство, через которое вы реально слышите собеседника.
2. Запустите речь или видео и проверьте индикатор системного звука.
3. Временно отключите микрофон, чтобы проверить только loopback.
4. Постепенно увеличьте усиление системного звука.
5. Попробуйте другое устройство с пометкой `Windows loopback`.

## Relay не подключается

- проверьте обычное интернет-соединение;
- убедитесь, что выбран режим Gemini Relay;
- посмотрите крупный статус сессии;
- `invalid HTTP response`, `connection refused` и `timeout` обычно означают недоступность relay;
- доступ к beta relay может быть временно ограничен.

## Gemini не отвечает

- дождитесь окончания состояния ожидания транскрипции;
- не запускайте повторный запрос, пока Gemini отвечает;
- `503 UNAVAILABLE` обычно означает временную перегрузку;
- `Location unavailable` в прямом режиме означает региональное ограничение;
- `Invalid API key` требует проверки локального ключа.

## Что приложить к Issue

- версию приложения и Windows;
- текст статуса ошибки;
- последовательность действий;
- названия типов аудиоустройств;
- только очищенный фрагмент лога.

Не публикуйте `.env`, API-ключи, токены, пароли, настройки с секретами или полный лог с транскрипцией.
