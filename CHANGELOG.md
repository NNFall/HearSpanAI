# История изменений

Здесь фиксируются заметные пользовательские изменения HearSpan AI. Версии `0.1.x` выпускались под рабочим названием AppGhost и сохранены как история private beta.

## [Unreleased]

Изменений после `0.4.0` пока нет.

## [0.4.0] - 2026-07-30

Коммерческий beta-контур: автоматический trial, персональные ключи, Telegram-бот,
тестовая YooKassa и защищённый учёт активных минут.

### Added

- 10-минутный trial для новой установки;
- экран доступа с остатком времени, проверкой, заменой и удалением ключа HearSpan;
- Telegram-бот с профилем, тарифами Start/Pro, ключами, поддержкой и тестовой оплатой;
- публичный лендинг, политика конфиденциальности, условия и страница поддержки;
- серверный control plane для trial, подписок, платежей и metering.

### Changed

- relay переведён на защищённый `wss://` и проверяет персональный ключ до запуска Gemini;
- прямой TCP-порт relay закрыт, публичный доступ проходит через TLS reverse proxy;
- активное время списывается после готовности Gemini Live с шагом до пяти секунд;
- transient-сбои control plane обрабатываются ограниченным идемпотентным retry;
- worker и relay корректно завершаются по `SIGINT`/`SIGTERM` без аварийного traceback.

### Security

- ключ HearSpan хранится через Windows DPAPI и передаётся только по TLS;
- Gemini, Telegram, YooKassa и межсервисные секреты не входят в EXE и репозиторий;
- серверная база не сохраняет транскрипции, промпты и ответы;
- release-файлы прошли отдельный secret scan.

### Verified

- desktop/relay: `237 passed, 1 skipped`;
- control plane: `782 passed, 3 skipped`;
- website: `35 passed`, browser E2E: `15 passed`;
- реальный trial дошёл до Gemini Live, списал 5 секунд и закрыл lease с остатком 595 секунд;
- PostgreSQL backup восстановлен в одноразовую БД с совпавшими migration и counts;
- установщик проверен автономным запуском, тихим обновлением и SHA-256.

### Beta limitations

- YooKassa принудительно работает в test mode, реальные списания отключены;
- установщик пока не подписан цифровой подписью;
- совместимость Windows loopback зависит от выбранного аудиоустройства и драйвера.

## [0.3.0] - 2026-07-28

Защищённый BYOK и отдельное окно потокового ответа.

### Added

- выбор между HearSpan Relay и прямым подключением с личным Gemini API key;
- опциональное хранение ключа через Windows DPAPI без открытого секрета в `settings.json`;
- отдельный capture-visible overlay с прозрачностью, always-on-top и пропуском мыши;
- сохранение положения и параметров overlay между запусками;
- безопасная заготовка входа через внешний браузер для будущего личного кабинета.

### Fixed

- BYOK без ключа теперь завершает запуск с понятной ошибкой, а не оставляет UI в состоянии подключения;
- режим Relay/BYOK всегда совпадает с фактически используемым провайдером;
- ключ из окружения сохраняет приоритет над значением из интерфейса;
- ошибка удаления сохранённого ключа показывается пользователю.

### Verified

- `149 passed, 1 skipped` на Windows;
- EXE прошёл автономный packaged smoke-test;
- установщик проверен по SHA-256.

## [0.2.1] - 2026-07-26

Настройки отделены от живого экрана приложения.

### Added

- шесть разделов настроек: обзор, аудио и транскрибация, AI и модели, промпты, горячие клавиши, диагностика;
- редактируемые Live-модель и модель финального ответа;
- ввод Gemini API key только для текущего запуска без сохранения в `settings.json`.

### Changed

- выбор провайдера, микрофона и системного звука перенесён в настройки;
- кнопка «Настройки» открывает окно напрямую без дополнительного dropdown;
- проценты усиления больше не перекрываются нативными стрелками;
- главный экран сфокусирован на сессии, ответе, транскрипции и живых аудиоконтролах.

### Verified

- `126` автоматических тестов прошли на Windows;
- packaged smoke-test подтвердил автономный запуск `HearSpan.exe` версии `0.2.1`;
- установщик проверен по SHA-256 и интерфейс просмотрен при компактном и desktop-размере.

## [0.2.0] - 2026-07-26

Первый установочный выпуск под названием HearSpan AI.

### Added

- адаптивный интерфейс для окон от `960x640` до `1920x1080`;
- командная панель, отдельные источники звука и компактный аудиомикшер;
- вкладки полного ответа и совета на компактном окне;
- копирование и фокусный режим полного ответа;
- локальные Lucide-иконки и дизайн-система Graphite Signal.

### Changed

- приложение, EXE, установщик и ярлыки переименованы в HearSpan AI;
- Start/Stop объединены в одну заметную кнопку состояния сессии;
- настройки переработаны в отдельные разделы с левой навигацией.

### Compatibility

- старые настройки и логи AppGhost обнаруживаются автоматически;
- сохранен идентификатор установщика для обновления поверх предыдущей beta.

### Verified

- `124` автоматических теста прошли на Windows;
- packaged smoke-test подтвердил автономный запуск `HearSpan.exe` без Python;
- интерфейс проверен на пяти размерах окна.

## [0.1.2] - 2026-07-22

Первая оформленная private beta и последняя версия под названием AppGhost.

### Fixed

- единые DPI-независимые стрелки выпадающих списков и меню;
- длинные названия аудиоустройств больше не перекрывают элементы управления;
- открытое и закрытое состояния меню визуально различаются;
- версия Windows EXE синхронизирована с версией приложения.

### Verified

- автоматические тесты прошли на Windows;
- установщик проверен на отдельном компьютере без Python;
- микрофон и системные loopback-устройства обнаружились после чистой установки.

## [0.1.1] - 2026-07-22

### Changed

- настройки разделены по категориям;
- переработаны основные кнопки управления сессией и звуком;
- увеличена центральная область полного ответа.

### Fixed

- блокировка преждевременных и повторных запросов по состоянию сессии;
- исправлены наложения элементов при размере окна `1024x720`.

## [0.1.0] - 2026-07-22

### Added

- Windows-установщик без зависимости от Python;
- одновременная транскрибация микрофона и системного звука;
- потоковые Markdown-ответы Gemini через relay;
- промпты, усиление, mute и горячие клавиши;
- сохранение пользовательских настроек;
- локальные диагностические логи.
