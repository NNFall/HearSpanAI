# Поддержка

Для обычных вопросов по доступу, ключу и тестовой оплате используйте раздел **Поддержка** в [@HearSpan_bot](https://t.me/HearSpan_bot?start=support). Для воспроизводимых ошибок приложения создавайте GitHub Issue.

## Сообщить об ошибке

Создайте [Bug report](https://github.com/NNFall/HearSpanAI/issues/new?template=bug_report.yml) и укажите:

- версию приложения;
- Windows 10 или 11;
- выбранные типы аудиоустройств;
- точный текст крупного статуса ошибки;
- последовательность действий и ожидаемый результат.

Перед публикацией удалите из материалов API-ключи, токены, пароли, персональные данные и транскрипцию разговора.

## Предложить функцию

Используйте [Feature request](https://github.com/NNFall/HearSpanAI/issues/new?template=feature_request.yml). Опишите проблему пользователя и желаемый результат, а не только конкретную кнопку или технологию.

## Безопасность

Для уязвимостей используйте инструкции из [SECURITY.md](SECURITY.md), а не публичный Issue.
